校方手册将中国银行 ATM 列在上园服务中心。当前用上园区域代表点近似定位，没有设备点坐标。实时可用性及校外访客能否进入仍待核对。距离只用于验证查询流程。

中信银行深圳港中大支行由[中信银行公告](https://www.citicbank.com/about/companynews/banknew/message/201911/t20191105_82445.html)核对。距离使用[港中大深圳下园区域](https://www.openstreetmap.org/way/533650675)的[代表点](https://mapcarta.com/W533650675)。具体入口、当前营业及访客通行情况待核。

京基·御景中央花园（一期）区域参考点距学校参考点约 2.66 公里（直线估算）。政府名单只出现整个小区名称，未区分期数；一期身份以 OSM 对象为线索，边界、出入口和实际通行仍待现场核实。

龙城支行以银行历史地址和 2026 年产品目录核对名称；OSM 对象是“中粮祥云国际写字楼2栋”，不是银行网点本身。建筑参考点距学校参考点约 2.10 公里（WGS84 直线估算）。地址属于同一栋楼的判断仍需现场核对，地图标记不是支行门口，当前营业与准确入口未知。2026 年目录列出支行名称，不等于证明今日营业。

京基二期、睿智华庭、阳光天健城的区域参考点距学校参考点分别约 2.42、2.38、1.89 公里（WGS84 直线估算）。名称或门牌线索来自上述政府资料，坐标来自 OSM 区域，不等于小区入口；边界和当前状态仍待实地核对。2026-11-11 增加这三条后，试点地点共 8 条，仍不能称为 3 公里范围内的完整清单。
