# 邻境 · 银行现场核对记录

建立于 2026-11-12。此表用于收集尚未入库的银行点位证据。下方地址是公开资料中的待核对线索，**不是本人已到场确认的结论**。现场记录应填写实际观察日期，不能用地图搜索页代替。不要拍摄客户、银行卡、工作人员证件或其他个人信息。

- 清单地址：深圳市龙岗区园山街道颐安都会中央三期 2S-05 至 2S-10 商铺。
- 已有线索：2026-11-10 本机高德临时查询曾显示同名候选，距学校约 659 米；截图门牌写法与银行清单不同。该距离仅是接口结果，不作数据库坐标。
- 待核对：是否仍有该支行；现场门牌是否落在上述商铺范围；网点入口与 ATM 是否各自独立；营业/暂停状态；能否取得允许复用的网点或同栋建筑坐标。
- 现场日期、实际门牌、观察结果、证据照片编号：**待填写**。
