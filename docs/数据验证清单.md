## 报告解读

首次真实报告：`../reports/验证报告_20261106_100523_549734.md`。本次工具未保存原始地点列表，尚不能从报告中进行逐条真实性核验。

字段完整率 = 样本中包含有效字段的记录数 / 本次返回的样本记录数。

样本为 0 时，比例应标为不适用；不能写成 100%。该指标不衡量数据真实性，需要另做人工抽查。

错误码、服务无权限、网络失败、找不到学校，都应如实保留为待解决问题。不得用测试数据替代真实采集证据。
