## 入库门槛

1. 有可追溯的地点身份依据，不把学校招生范围直接当作地址。
2. 有来源明确、许可条件可核对的坐标，并通过学校周边 3 公里直线距离校验。
3. 明确标注坐标是入口点、建筑物点还是区域代表点。
   高德坐标与现有 OSM 样本的 WGS84 坐标不能直接混算距离，必须先转换到同一坐标系。
4. 对无法证实的营业、设备可用、房价、物业费等字段保持未知。
5. 入库后在页面标为未核验；资料核对和现场核验分别记录。
