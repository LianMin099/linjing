## 提交前仍要处理

1. **评审访问**：2026-11-14 已将 GitHub 设为公开。未登录浏览器能打开仓库首页、源码及 65 条提交历史。最终提交时使用 GitHub 链接；Gitee 仅作备份。公开前已检查当前文件与历史的敏感路径和常见密钥格式，但模式检查不能保证识别所有敏感内容。
2. **实际地点核对**：对银行网点与 ATM 核对门牌、入口、当前营业或可用状态；对小区核对名称、位置及住宅属性。现有部分坐标为楼宇或区域代表点，不能说成精确入口。现场核验前保持页面“未核验”。
3. **数据使用范围**：明确后续采集源是否允许存储和展示原始地点数据。高德临时查询只作为候选线索；未核对许可的接口结果不批量入库。
4. **演示与文档一致**：已在独立演示库从空数据库启动，在浏览器走完“查询→提交纠错→管理员审核→地址变化→核验状态变化”并保存[四张真实页面截图](验证证据/本机业务闭环复现_20261113.md)。2026-11-13 已逐页核对 PDF 与当前样本、接口、数据表和已实现功能，结果见[初赛材料一致性核对](初赛材料一致性核对.md)；冻结初赛版本后仍须再对照一次。如需录屏，另行制作。
5. **部署边界**：已验证本机干净目录运行，尚未验证独立服务器或公网服务。提交材料须如实标为后续工作，不能把本机复现称为服务器部署。
