# 数据许可与 3 公里参考点

## 当前试点数据

随仓库提供的 9 条地点仍是 **OpenStreetMap（OSM）代表点试点样本，仅用于原型流程验证，不作为已核实的正式地图数据源**，不是已经核对过入口、营业状态与完整覆盖的正式地点名录。`samples/pilot_osm.json` 逐条记录 OSM 对象链接、许可链接及 WGS84 坐标系；旧采集时间没有留下可核实记录，因此 `collected_at` 为 `null`，不能补造日期。SQLite 中的 `imported_at` 只表示本机导入时间，不能冒充原始采集时间。

[OSM 官方版权页](https://www.openstreetmap.org/copyright)说明，地图数据采用 ODbL，使用者需要署名，并在以其数据构建衍生数据库时遵守相同许可。页面及源码均保留 OSM 署名与许可链接。仓库目前**没有单独的代码开源许可证**；代码可查看不等于他人获得任意再许可。代码许可、OSM 数据许可和其他资料的使用许可是三件事。

高德在线 POI 搜索仅在当前页面展示候选，不写入 SQLite、样本文件或仓库。[高德开放平台服务协议第 3.5 条](https://lbs.amap.com/pages/terms/)对服务数据的直接存储和缓存有限制。因此不能因为已有 API Key 就将高德搜索结果批量收进试点库。新增来源文件必须由管理员先核对使用许可、坐标与地点身份；候选阶段不进入正式查询结果。

## 3 公里口径

现有试点样本按 `114.210700, 22.687940`（经度、纬度；WGS84）计算 3 公里范围。此点来自 [OSM 学校面对象 way/330064305](https://www.openstreetmap.org/way/330064305) 的历史代表点，**不是学校大门，也不是腾讯或高德官方校址点**。`import_places.py` 使用球面直线距离判断地点是否落入以该点为圆心的 3 公里半径；页面中小区与银行之间的距离则按两个地点代表点计算。两种距离均不代表步行路线。

换成其他校址点会改变边界结果，不能把不同坐标系的点直接混算。当前 9 条样本只对上述历史参考点符合导入范围，不宣称对其他学校坐标点同样符合。若未来更换参考点，须记录来源与坐标系，重新验证每条样本及 PDF 的数量陈述。
