# 本机采集任务复现（2026-11-14）

执行 `python -B verify_collection.py`。脚本在临时目录创建来源 JSON 和 SQLite，不使用本机试玩数据库、地图 Key 或外部接口。实测结果：定时触发读取来源文件，9 条进入待审核候选且未直接入库；确认一条银行候选后入库；模拟来源名称与地址变化并再次确认，版本由 1 升至 2，`place_changes` 记录 `name, address`；人工纠错审核后来源再次变化，保留人工地址而更新名称；来源文件缺失时任务标为失败并保留原因，恢复文件后重试成功。脚本还启动真实本机服务并等到定时任务被服务循环触发，再通过网页管理员登录及候选审核接口确认一条候选；`verify_clean_launch.py` 另行验证原有查询、纠错、审核与重启保存。

此证据只验证**本机文件与模拟变更的程序行为**。它不证明外部接口允许持久化采集，不证明 OSM 代表点是精确入口，也不证明服务关闭期间定时任务会运行。高德实时 POI 候选未进入本机任务队列。
