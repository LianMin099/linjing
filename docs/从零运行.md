# 邻境从零运行与验证

## 准备

- Windows 电脑，安装 Python 3.7 或更新版本，并能在终端执行 `python`。
- 下载整个仓库，不要只下载单个脚本。运行入口所需的样本在 `samples/pilot_osm.json`。
- 本地查询、纠错和审核不需要高德 Key，也不需要联网；没有地图配置时显示离线位置示意图。

## 启动

在项目文件夹双击 `打开真实地点查询.cmd`，或在终端运行：

```text
python -B run_pilot.py --open-browser
```

首次启动会在 `data/pilot.sqlite` 建库并导入 5 条样本。终端会显示本机网址与本次管理员口令。打开网址后可以选小区、范围和设施类型；要审核纠错时使用启动窗口显示的口令登录。关闭启动窗口即停止服务，数据库仍保留。再次启动时相同来源编号会跳过，不覆盖已审核的地址。

如要和自己的试玩数据隔离，请运行：

```text
python -B run_pilot.py --db data/review.sqlite --open-browser
```

不要把 `data/` 文件夹、管理员口令或地图密钥上传到仓库。网页服务仅监听本机 `127.0.0.1`，当前**不是公网部署**。

## 自动复现检查

在项目文件夹运行：

```text
python -B verify_clean_launch.py
```

脚本把运行所需源码复制到自动清理的临时目录，用新的数据库验证：导入 5 条、网页查询、提交纠错时不改原地址、管理员审核、重启后修订保留。它不读取本机试玩数据库和地图密钥，验证通过会在终端显示结果。

本项验证只证明在同一台 Windows 电脑上的干净目录可运行；独立服务器、公网访问、长期外部接口配额和实际设施现状仍需分别验证。
