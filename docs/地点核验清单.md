# 邻境试点地点核验清单

本清单用于把“有公开来源”“位置准确”“目前可使用”分开。系统现有的三个样本只能证明查询、地图和纠错流程能运行，不能证明学校周边的银行或小区已完整覆盖。

| 地点 | 已有资料 | 仍须核对 |
| --- | --- | --- |
| 嘉欣园 | OpenStreetMap 区域代表点、龙城街道公开资料 | 小区边界与地图点位、名称现状、从学校出发的实际到达方式 |
| 中信银行深圳港中大支行 | 中信银行历史公告、港中大（深圳）下园区域代表点 | 当前是否营业、准确门牌和入口、校外访客是否可进入 |
| 中国银行港中大（深圳）上园 ATM | 校方入住手册、上园区域代表点 | 设备是否仍在、是否可用、准确位置和访客通行条件 |

资料链接与坐标使用说明见[样本说明](../samples/README.md)。现有银行和 ATM 的地图点是区域代表点，不是设施入口。历史公告和入住手册不能单独证明 2026 年仍在营业或可使用。

## 你可以怎样核验

1. 打开“真实地点查询”并登录管理员模式。在地点卡片查看来源。
2. 打开原始网页或 PDF，确认地点名称、类型、地址和资料日期。记录你实际看到了什么，不要把推测写成事实。
3. 只在已经核对资料后，在页面底部的“资料核验记录”选择地点、填入 HTTPS 来源链接，并写清仍未知的项目。选“公开资料已核对”也不会把地点标成现场已验证。
4. 如方便实地走访，再记下日期、门牌、出入口、营业或设备状态及可供核查的照片。不要拍摄或公开他人个人信息。当前页面没有“现场已核实”选项；实地结果需单独整理，待流程实现后录入。
5. 任何地址纠错通过审核后，重新检查该地点的新版本。旧版本的核验记录不会自动套用到新地址。

本机 `data/pilot.sqlite` 曾用于试玩，可能含任意测试地址。展示真实资料时使用单独的 `data/review.sqlite`；对照来源和现场信息确认后，再说明哪些是已核对，哪些仍未知。
