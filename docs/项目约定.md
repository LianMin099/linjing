## 核心用户流程

采集真实来源 → 清洗与去重 → 保存来源及版本 → 地图/列表查询 → 用户提交纠错 → 管理员核实 → 更新记录 → 查询结果同步变化 → 用户查看处理结果。

补充流程：按区域汇总查询热度，将较热门且较久未核验的区域优先加入更新任务。

## 初赛最小范围

1. 试点范围内银行与小区的真实采集证据。
2. 地图与列表展示、类别筛选、小区周边银行查询。
3. 用户反馈、管理员审核、版本记录与展示更新。
4. 可复现运行说明、关键路径验证、源码提交历史。
5. 不超过 10 页设计文档，含业务流程图、架构图、接口、关键表结构及技术/数据/时间可行性。

## 实现原则

- 实际资料缺失显示未知，不用 AI 编造。
- 区分直线距离和步行距离，记录坐标体系。
- 区分银行支行与 ATM；名称相同不代表同一地点。
- 人工核验值不能被下一次旧来源数据直接覆盖。
- 纠错、重新采集、审核均留下状态与时间。
- 每一步交付：目标、操作、知识点、验收证据。
