# 邻境

邻境是智能应用创新开发大赛赛题四（银行与小区信息采集及查询系统）的参赛项目，以深圳信息职业技术大学周边为试点。

初赛设计说明见[3 页 PDF](docs/邻境_初赛设计说明.pdf)，可编辑内容见[Markdown 草稿](docs/初赛设计说明草稿.md)。PDF 由 `build_design_pdf.py` 生成，需安装 ReportLab；提交前应再次核对内容和页数。

## 当前进度

已完成学校定位及周边银行、小区的接口验证。以学校为中心查询 3 公里范围，两类各返回第一页 10 条。名称、地址和有效坐标在两组样本中的字段覆盖均为 10/10，地点分类与真实性仍待抽查。

## 运行接口验证

在 Windows 的终端执行 `python probe_amap.py`，按提示在本机输入高德 Web 服务 Key，选择对应的学校地点。程序最多发出三次请求，并在 `reports/` 生成字段覆盖报告。使用 `python probe_amap.py --self-test` 可在离线环境检查字段统计逻辑。

[查看首次验证报告](docs/验证证据/首次接口验证_20261106.md)

## 运行离线流程演示

在 Windows 双击 `打开邻境演示.cmd`，或在项目目录运行 `python demo_web.py --open-browser`。在浏览器依次点击「查附近」「提交纠错」「审核通过」。启动窗口会显示本机访问地址，关闭窗口后演示结束。

在项目目录执行 `python demo_workflow.py`。演示使用虚构地点，依次展示周边查询、提交地址纠错、审核通过及查询更新。数据库只存在于本次运行的内存中。演示不需要 Key 或网络。

真实样本查询已经支持本机 SQLite 持久保存、纠错审核以及可选的高德在线地图。外部定时采集和独立部署仍未完成。

## 一条命令启动试点

从源码目录执行 `python run_pilot.py`，再打开终端给出的本机地址。需要自动打开浏览器时，运行 `python run_pilot.py --open-browser`；Windows 也可双击 `打开真实地点查询.cmd`。该入口使用 Python 标准库，会自动创建数据库并导入随项目提供的样本。

可用 `--db` 指定数据库位置，用 `--port` 固定本机端口。首次会新增样本，之后再次启动会跳过已有记录并保留本机修订。服务仅监听本机。

## 地点数据入库

双击 `打开真实地点查询.cmd` 可以导入并浏览首批真实样本，默认范围为 3 公里。访客可在银行或 ATM 查询结果下提交地址建议。审核时使用启动窗口显示的本次口令登录管理员模式。口令与登录状态随程序重启失效，已通过的本机修订和审核记录保存在 `data/pilot.sqlite`。地点来源、坐标精度与许可见[样本说明](samples/README.md)。

选择小区可查附近银行和 ATM；在银行网点卡片展开“网点周边小区”，可反向查看其 3 公里内已入库的小区，并点击切回该小区的查询。两向距离均按样本 WGS84 坐标计算直线估算值，不代表道路距离或实际可进入性。

管理员登录后，页面底部可以为地点保存“公开资料已核对”或“仍需现场核实”的记录，填写可追溯的 HTTPS 证据链接和说明。查询卡片会显示当前地点版本的核验状态；地址纠错审核通过后版本增加，旧核验记录仍保留，但当前版本重新显示“未核验”。“公开资料已核对”只表示所填证据支持说明，不代表银行营业、ATM 可用或校外访客可进入。亲自核对前请勿填写已核对；具体待办见[地点核验清单](docs/地点核验清单.md)。

扩充数据前先查看[新增地点候选](docs/新增地点候选.md)。候选名单与已入库样本分开，只有取得可追溯坐标并通过范围检查后才入库。

`data/pilot.sqlite` 是本机试玩数据库，可能包含测试地址，不能直接作为参赛的真实数据结论。准备展示时，可用 `python run_pilot.py --db data/review.sqlite --open-browser` 打开独立数据库，再逐项核验。不要删除原数据库，以免丢失纠错和审核记录。

`python import_places.py 数据文件.json` 只检查数据。确认允许存储后，可添加 `--db data/linjing.sqlite` 写入已创建的 `data` 目录。入库后保留来源、使用依据和导入时间。同一来源编号重复导入会跳过，已审核修改不会被覆盖。网页教学演示继续使用独立的虚构数据。

JSON 顶层包含 `coordinate_system`（目前只接受 `WGS84`）、`source_url`、`permission_url`、`school` 和 `places`。`school` 包含 `longitude`、`latitude`、`source_url`、`permission_url`。`places` 中每条包含 `source_id`、`kind`（`bank`、`atm` 或 `community`）、`name`、`address`、`longitude`、`latitude`。程序检查链接格式和 3 公里范围，使用依据需人工核对。

## 在线地图（可选）

在高德应用「邻境」下创建 Web端（JS API）Key 和对应安全密钥。Windows 双击 `配置地图.cmd`，将两项分别粘贴到星号输入框并点击「保存配置」。配置仅在本机 `data/amap.local.json` 保存，此目录被 Git 忽略；请勿分享文件或上传截图。然后关闭旧启动窗口，重新双击 `打开真实地点查询.cmd`。无需在线地图时仍可使用示意图和列表。

浏览器会加载高德地图 JS API，本机服务器只代理官方地图样式、初始化和坐标转换所需接口。安全密钥不会写进源码或网页；JS API Key 会作为浏览器加载脚本时的公开参数使用。样本原坐标为 WGS84，显示地图前由高德转换为 GCJ-02，不把转换结果写回样本数据库。点击标记跳到地点卡片，卡片可定位地图，筛选时两边同步。距离仍是原坐标计算的直线估算，部分银行/ATM 只用区域代表点，入口待核实。地图加载失败时展示离线示意图。

当前验证仅覆盖本机试点，不代表独立服务器部署已完成。
